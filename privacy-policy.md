Политика конфиденциальности

Настоящая Политика конфиденциальности распространяется на веб-версию проекта «Currency Converter – Конвертер валют онлайн», размещённую на платформе GitHub Pages (https://dennymaverick.github.io/Convertation_project), и соответствующее мобильное приложение Android, распространяемое через RuStore.

1. Сбор и использование данных

Приложение «Currency Converter – Конвертер валют онлайн» самостоятельно не запрашивает, не собирает, не хранит и не передаёт персональные данные пользователей. Локально сохраняются только настройки интерфейса, описанные в настоящей Политике. Приложение использует интернет-соединение для получения актуальных курсов валют из открытого источника — Центрального банка Российской Федерации (ЦБ РФ). Полученные курсы валют используются исключительно для выполнения расчётов и отображения результатов конвертации.

2. Точность расчётов

Результаты конвертации имеют информационный характер и предназначены для ознакомительных целей. В отдельных случаях, особенно при расчёте больших сумм, возможны небольшие погрешности, связанные с особенностями вычислений с числами с плавающей точкой.

3. Файлы cookie и сторонние сервисы

На момент публикации настоящей редакции Политики в проекте не используются сторонние сервисы веб-аналитики и рекламные сети. В случае подключения таких сервисов, включая Яндекс.Метрику и Рекламную сеть Яндекса (РСЯ), настоящая Политика будет дополнена сведениями о целях использования соответствующих сервисов, категориях обрабатываемых данных и применяемых технологиях, включая файлы cookie.

4. Локальное хранение настроек

Для обеспечения корректной работы и удобства использования веб-версии и мобильного приложения используется механизм локального хранения данных (localStorage). В localStorage сохраняются исключительно пользовательские настройки интерфейса:

	- выбранный язык (ru / en);
	
	- выбранная цветовая тема (moon / dark).
	
Указанные настройки хранятся локально на устройстве пользователя и используются исключительно для сохранения выбранных параметров интерфейса. Эти сведения не передаются владельцу проекта и не используются для идентификации пользователей.

5. Хостинг и техническая информация

Веб-версия проекта размещена на платформе GitHub Pages, предоставляемой компанией GitHub, Inc. При посещении веб-версии хостинг может автоматически обрабатывать техническую информацию, включая IP-адрес, дату и время обращения, запрашиваемую страницу, тип браузера и операционную систему пользователя. Такая обработка осуществляется инфраструктурой GitHub в целях обеспечения работоспособности, безопасности и защиты сервиса.

Владелец проекта не имеет прямого доступа к внутренним техническим журналам GitHub.
Дополнительная информация об обработке данных доступна в [Политике конфиденциальности GitHub](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).
