Политика конфиденциальности

Приложение "Currency Converter – Конвертер валют онлайн" не собирает, не хранит и не передаёт персональные данные пользователей.

Приложение использует интернет только для получения актуальных курсов валют из открытого источника.

Полученные курсы валют используются исключительно для выполнения расчётов и отображения результатов конвертации.

Точность расчётов

Результаты конвертации имеют информационный характер и предназначены для ознакомительных целей. В отдельных случаях, особенно при расчёте больших сумм, возможны небольшие погрешности, связанные с особенностями вычислений с числами с плавающей точкой.
